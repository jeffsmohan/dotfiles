# keyboard

Dated snapshots of my [ZSA Moonlander](https://www.zsa.io/moonlander) layout. Source of
truth lives in [Oryx](https://configure.zsa.io/moonlander/layouts/NpZPB/latest/0).

## Snapshots

Each snapshot is manually saved under `archive/<YYYYMMDD>/`, dated by when the revision
was made in Oryx.

1. In Oryx, open the layout and click **Download source**.
2. `mkdir archive/<YYYYMMDD>/`.
3. Copy the downloaded zip archive in.
